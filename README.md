# openai-comparator-api

Set up:
1. Clone
2. Open folder in Visual Studio Code
3. Ctrl + Shift + P -> Python: Create Environment -> venv -> python version -> select requirements.txt
4. In the terminal -> pip install streamlit
5. To run BE - select main.py -> click search bar, top middle -> Start Debugging -> Python Debugger -> FastAPI
6. To run FE - in the terminal -> streamlit run ui.py
